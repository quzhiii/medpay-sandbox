# 方法论

## 事件账本
所有仿真过程被记录为事件流，包含：入院、诊疗、出院、结算、入组等。事件具有时间戳与增量，确保可回放与可审计。

## 双引擎对照
同一病例同时进入 DRG 与 DIP 结算，形成支付差异对照，定位机制差异对医院行为的影响。

## 点值分母假设
DIP 点值 = 预算 / 区域总点数。本系统将分母显式呈现，便于理解“点值贬值”与规模效应。

## 解释器三分解
每次 SETTLE 生成解释：
- 结构效应：病例结构/权重/点数带来的基础收入。
- 价格效应：费率或点值变化导致的增减。
- 管理效应：特例单议、超额谈判、政策行为影响。

三项之和与支付变化一致。

## 可复现导出
导出提供完整参数、事件账本与结算结果，可用于二次分析与复现验证。
